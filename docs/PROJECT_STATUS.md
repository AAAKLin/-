# Project Status

Last updated: 2026-10-13（在本机实际构建、启动并运行测试后更新）

## Current stage
**第一版已实现并跑通**：后端 API + 前端响应式页面 + SQLite 持久化 + 自动化测试，均在开发机上实际启动并运行通过。

## 技术选型（已落地，非计划）
- 后端：Node.js 22 + Express 4，分层结构（routes → services → repositories）。
- 数据库：Node 内置 `node:sqlite`，数据文件 `data/fitness.db`；无需安装原生依赖，无外部服务。
- 前端：零构建原生 ES 模块 + 原生 CSS，无打包步骤、无前端框架。
- 测试：Node 内置 `node:test`（单元测试 + 集成测试），另有 `npm run smoke` 冒烟脚本。
- 成本：本地运行，零付费依赖；营养计算与目标推算为确定性代码，不依赖 AI。

## 已实现
- **今日行动中心**：训练状态（未记录/已完成/部分完成/今天没练）、热量与三大宏量进度条、体重腰围趋势缩略图、规则生成的建议（最多 4 条）、快速记录（训练/饮食/体重）入口。
- **训练**：按档案生成一周新手计划（可用天数、时长、器械、经验、身体限制关键词过滤动作）；7 天切换；快速记录；明细记录（组数/次数或秒数/主观强度/不适），计划值自动预填；训练历史；规则化调整建议并可一键应用（连续轻松加量、连续吃力减量、有不适退阶）。
- **饮食**：按餐次记录实际摄入；改克数/份数自动重算营养并与目标对比；建议菜单模板（平价优先，可一键"记到今天"）；常用食物增删改；食谱（多食材、份数）增删改与"记一份"。
- **进度**：体重/腰围折线趋势 + 线性回归得出的每周变化、BMI 参考、训练依从（明确区分"未记录"与"没练"）、饮食记录覆盖率、每周训练次数柱状图、测量记录增删。
- **数据持久化**：SQLite 落盘，刷新/重启后保留（集成测试覆盖）。
- **备份恢复**：导出 JSON；恢复必须二次确认（未确认直接拒绝）；备份文件校验失败时不破坏现有数据。
- **档案与设置**：身高体重/年龄/性别/活动量/目标/经验/天数/时长/器械/限制/预算；目标自动估算（Mifflin-St Jeor + 活动系数 + 宏量分配，带假设说明）并可手动覆盖或重新估算。
- **合成演示数据**：`POST /api/demo/load`，只补充缺失日期，不覆盖已有记录。

- **UI 设计系统（2026-10-13 晚改版）**：参照 shadcn/ui 的设计令牌用原生 CSS 重写全部样式（不引入 React/Tailwind/构建链，保持零构建）；主色近黑、细边框、弱阴影；新增深色模式（右上角太阳/月亮切换，跟随系统 + localStorage 记忆）；emoji 全部替换为线性 SVG 图标；图表颜色随主题自适应。
- **AI 密钥安全机制（2026-10-13 晚新增）**：支持三种密钥提供方式（.env 直填 / 密钥文件路径 / 环境变量名指向密钥文件）；密钥只存服务端内存，不进 config 对象、不写日志、不回传浏览器；提供 `GET /api/settings/ai-status` 自检接口（只返回是否配置 + 来源 + 前 2 后 2 位脱敏）。当前版本无任何 AI 调用，不配置密钥所有功能照常可用。
- **局域网访问（2026-10-13 晚完善）**：`.env` 中 `HOST=0.0.0.0` 后，同一 WiFi 的手机可访问（无登录密码，仅建议可信网络使用）。启动横幅会自动打印全部局域网地址，应用内「档案与备份 → 访问方式」也显示同样的地址；新增 `GET /api/settings/network` 返回本机/局域网访问地址与安全提示。

## 部署（2026-10-13 已上线）
- **分享链接：https://personal-fitness-manager.app.workbuddy.host/** （已实测：首页 200、`/health` 200、`/api/today` 返回正常数据、页面完整渲染）
- 部署形态：Node HTTP 服务（`deployedAs: http-service`），平台注入 `PORT`，源码上传后在沙箱安装依赖并启动。
- 为满足云端运行做的两处改动：
  1. `server/config.js`：`HOST` 默认值由 `127.0.0.1` 改为 `0.0.0.0`（云端平台只注入 PORT，默认绑本机会导致平台访问不到服务）。
  2. `.env`：移除写死的 `PORT=3100`（会覆盖平台注入的端口导致启动失败），仅保留 `HOST=0.0.0.0`。
- 云端与本地是**两份独立的数据库**：线上库为全新种子数据（本地 `data/` 未上传）；在手机上填的档案和记录不会同步到电脑，反之亦然。
- 数据安全说明：SQLite 文件在沙箱内，重新发布会以当前上传内容覆盖；本地 `.env` 与密钥文件不在上传范围内，线上也不持有任何密钥。

## Known issues / 限制
- 未做登录鉴权，按"个人本机使用"设计；若要公网部署必须先加认证（需用户同意后再动）。
- 食物营养值取自公开食物成分表的近似值，部分标记为"估算"，需用户自行修正。
- 无价格数据，"低预算"按食材类别与平价标记做启发式推荐，不是真实比价。
- 仅在 Windows + Node 22.22 环境验证过。
- 前端已用无头 Chrome（CDP + 390×844 移动视口 / 1440 桌面视口）逐页截图核验，布局正常；未在真机浏览器/真手机上验证过触屏体验。截图见 `screenshots/`。
