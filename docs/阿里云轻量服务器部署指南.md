# 阿里云轻量服务器部署指南（零基础版）

> 目标：把本项目部署到阿里云轻量应用服务器，让手机/电脑 24 小时都能访问，**数据存在服务器硬盘上，重启不丢**。
> 全程约 40 分钟，所有命令都可以直接复制粘贴。

## 0. 先理解原理（30 秒）

- 轻量应用服务器 = 一台 **24 小时开机、有公网 IP 的云电脑**
- 部署 = 把项目放到这台电脑上一直跑着，和你现在在自己电脑上 `npm start` 效果一样
- 数据库文件 `data/fitness.db` 也在这台电脑的硬盘上 → **重启、断电都不会丢数据**（这正是 Render 免费档做不到的事，也是选轻量服务器的核心理由）

## 1. 领/买服务器（学生免费一年）

1. 阿里云官网 → 顶部「产品」→「轻量应用服务器」（或搜索“轻量应用服务器”）
2. 选择**学生优惠**机型（需完成学生认证 + 实名认证）：通常为 **2 核 2G 1M 带宽，免费一年**
3. 镜像选择：**Ubuntu 22.04**（本指南按它写；选 Alibaba Cloud Linux 3 也类似）
4. 地域选择：**成都**（离你最近，访问延迟最低）
5. 购买/领取后，在控制台记住两样东西：**公网 IP** 和 **root 密码**（重置密码后重启生效）

> 2 核 2G 跑这个项目绰绰有余（一个 Node 进程 + 一个小数据库文件）。1M 带宽自己用完全够。

## 2. 连上服务器

零基础推荐用阿里云控制台自带的网页远程连接（不用装任何软件）：
控制台 → 轻量服务器列表 → 点你的服务器 → 「远程连接」→ 用 root 登录。

（也可以用自己电脑的 PowerShell：`ssh root@你的公网IP`，输入密码。）

## 3. 安装运行环境（逐段复制粘贴）

```bash
# 安装 Node 22（项目要求 22.5 以上）
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
node -v        # 显示 v22.x 即成功

# 安装 git 和 pm2（pm2 让程序崩溃自恢复、开机自启）
sudo apt-get install -y git
sudo npm install -g pm2
```

## 4. 把代码拉下来

```bash
cd /opt
sudo git clone https://github.com/AAAKLin/-.git fitness
cd fitness
sudo npm install --production
```

## 5. 配置并启动

```bash
# 创建配置文件（HOST 必须 0.0.0.0，否则外网访问不到）
sudo tee .env <<'EOF'
HOST=0.0.0.0
NODE_ENV=production
EOF

# 启动并设置开机自启
sudo pm2 start server/index.js --name fitness
sudo pm2 save
sudo pm2 startup        # 按它提示，把输出的那条命令再执行一遍
```

## 6. 开放端口（不做这步外网打不开）

阿里云控制台 → 你的服务器 → 「防火墙」→「添加规则」：

| 应用类型 | 协议 | 端口范围 | 来源 |
|---------|------|---------|------|
| 自定义 TCP | TCP | 3100 | 0.0.0.0/0 |

## 7. 访问

浏览器打开 **http://你的公网IP:3100**

- 手机浏览器打开后，菜单里选「添加到主屏幕」，用起来和 App 一样
- 想把网址发给别人也行，但注意：当前版本**没有登录密码**，知道网址的人都能打开

## 8. 日常维护（记住三条命令就够）

```bash
sudo pm2 status            # 看程序是否在跑（online 为正常）
sudo pm2 restart fitness   # 重启程序
sudo pm2 logs fitness      # 看日志，出问题时排查用
```

## 9. 以后更新代码（改了 GitHub 仓库之后）

```bash
cd /opt/fitness
sudo git pull
sudo npm install --production
sudo pm2 restart fitness
```

## 10. 数据与备份

- 数据库位置：服务器上 `/opt/fitness/data/fitness.db`，**重启不丢**
- **每周备份一次**：应用内「档案与备份 → 导出备份（JSON）」，把文件存到自己电脑或网盘
- 换服务器/搬家：在新环境用「选择备份文件恢复」即可把数据带走

## 11. 注意事项

- **免费到期时间设个手机提醒**；到期后按第 9 节的思路可以随时迁到别处（数据用备份带走）
- 想绑自己的域名：需要买域名 + **工信部备案**（约 1-2 周）；先用 IP:3100 访问不需要备案
- AI 功能（可选）：在 `.env` 里加一行 `AI_API_KEY=你的密钥`，再 `sudo pm2 restart fitness` 生效

## 常见问题（按顺序排查）

1. **打不开网页**：`sudo pm2 status` 看是否 online → 防火墙是否加了 3100 → 地址是否是 `http://IP:3100`（是 http 不是 https）
2. **启动报错提示 node:sqlite**：Node 版本低于 22.5，回第 3 节重装 Node 22
3. **页面能开但数据不对**：`sudo pm2 logs fitness` 看最后几行日志
